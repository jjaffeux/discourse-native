# Ten bugs proven red, then green

Each bug landed as two commits on `f0d0d298a`: a commit holding only a failing
test, then a commit holding only the production fix.
`tool/prove_bug_commits.py` checked out both commits of each bug in a scratch
worktree. Every test failed at its repro commit on the assertion below and
passed at its fix commit. All 17 checks held.

Rerun it from the repository root:

```sh
tool/prove_bug_commits.py docs/bug-fixes/2026-11-09-ten-bugs.manifest.json \
  --base f0d0d298a --out /tmp/proof.json
```
