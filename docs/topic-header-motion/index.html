About these studies

HTML/CSS approximations of the existing Native buttons, badges, avatars, sidebar and popovers. All interactions use local sample data. These are design proposals; browser motion is not a Flutter performance measurement.

The current header switches between expanded and compact layouts over 380 ms and expands on any upward scroll. These studies explore alternatives to that behavior.
