One capsule. The right signal.

Combined capsules for both chat and notifications. Chat counts direct messages, mentions, and watched-thread activity; ordinary unread chat keeps a dot. Preview the core color roles below.

Combined capsule

Selected

The same capsule holds chat and bell counts. Its tint follows the activity: theme accent for ordinary notifications, success for urgent chat and personal messages, danger for reviewables.

Clear grouping · more visual emphasis
04

Count replaces bell

Show a 28px count circle when activity is waiting; restore the bell at zero. One visual occupies the same button slot.

Stable width · notification identity less obvious
05

Dot here, count in menu

Use the same 8px dot as chat, with its 2px ring. Open notifications to see the exact count. The header stays equally quiet at 2 or 128.

Most compact · exact count needs a click
06

Count beneath the bell

Stack a small count beneath the icon inside its 44px target. No badge crosses the icon, and neighboring buttons keep their positions.

Stable width · different vertical rhythm

Color audit · Discourse core

ActivityCore colorPresentation
Ordinary unread chat; unread bell; topic mentions and replies--tertiary-med-or-tertiaryChat dot; bell capsule
Chat DMs, mentions, watched-thread activity--successChat count capsule
Personal messages--successBell capsule; priority over reviewables
Reviewables--dangerBell capsule; priority over regular unread
New topics / new replies / unread post counts--tertiary-med-or-tertiaryTopic dots or numeric badges
Ordinary sidebar unread--token-color-background-accent-subtleDot; urgent chat still uses success

These are theme roles, not fixed universal colors. Preview swatches use Native’s default light/dark palettes. Site themes supply their own values. The chosen capsule uses a soft tint of the role with darker/lighter text; core’s solid badges use --secondary text. “Only mentions”, “DMs and mentions”, “Never”, and Do Not Disturb continue to govern chat visibility.

Source: local pr-discourse checkout 438ea4de, header.scss, badges.scss, sidebar.scss, tokens.scss, chat-unread-indicator.scss, and the chat header indicator component. WCAG themes also override some solid badge colors.
