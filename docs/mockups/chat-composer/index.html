DISCOURSE NATIVE / DESIGN STUDIES

A little more room to talk.

Three composer layouts built from the Native kit’s existing vocabulary.

HTML/CSS studies, not live Flutter widgets. Geometry follows DControlSize; colors follow AppTheme.dark/light. No new kit APIs required for these layouts.
Native component mapping & implementation notes

Use package:discourse_native/discourse_ui.dart when implementing the selected direction.

01: DInputGroup → DInputGroupControl(multiline: true) wrapping the existing ComposerEditor; inlineStart / inlineEnd DInputGroupAddon; DInputGroupButton.icon, regular size.

02: Same editor adapter, with DInputGroupAddon(blockEnd) containing ghost add/emoji actions and a primary Send button. Reply context uses blockStart with the existing reply preview content and ghost cancel button.

03: DInputGroup + editor adapter; a sibling Row of DButton ghost actions and a primary Send button. DKbd / DShortcutKeycaps for desktop hints.

Add opens the existing upload/GIF menu; emoji opens the existing emoji picker. This study’s menu and emoji interactions are local demonstrations. Sending only appends a local preview message.

Sources: lib/src/styleguide/examples/input_group_examples.dart, lib/src/ui/components/d_input_group.dart, lib/src/ui/foundation/control_style.dart, lib/src/theme/app_theme.dart. Retain the existing editor for rich text, mentions, uploads and IME behavior.
