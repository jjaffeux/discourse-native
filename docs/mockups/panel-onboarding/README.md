# Two-panel start-page guide mockups

Open `index.html` in a browser to compare three HTML/CSS concepts in dark and light appearance.

1. **Compact guide** reduces the current tutorial to three shortcut tiles and one short tip. Recommended for the start page because it leaves the recent content visible.
2. **Show the destination** illustrates where Shift-click sends a link. It is more explanatory, but occupies more space.
3. **Quick reference** groups gestures by destination and preserves the context-menu and tab-drag advice.

These are visual studies of the existing tutorial in `lib/src/shell/new_tab_page.dart`, not application code. Any implementation should compose Native UI kit components and retain the existing dismissal behavior.
