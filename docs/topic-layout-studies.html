The tradeoff

Try the interaction

Stable ownership. Switching topics never changes the draft’s destination. Return to its topic from the composer. List position and per-topic reading position survive navigation.

Width before column count. Below 1100px, navigation opens from a button beside the rail. Below 890px, the composer moves below the reader. Its preferred right dock returns when room allows.

Prototype scope. Sample content and in-memory drafts. Reply simulates a local post. These are HTML/CSS design studies; application implementation would use the existing Native UI kit.
