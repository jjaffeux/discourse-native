Rethinking how topic context should work in the native client

SJ
samteam · 12 minutes ago
#1

Topic metadata is useful while reading, but it currently competes with the title and the actions in the header. The proposal is to let the header do one job: orient you in the conversation.

A calmer reading surface

Move persistent context to the right sidebar, where it remains available without changing the rhythm of the post stream.

  • Keep category, tags, and assignments visible.
  • Use one tabbed container for related and suggested topics.
  • Make the sidebar useful without making it visually loud.
