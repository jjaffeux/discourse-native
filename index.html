Discourse Native

An experimental native Discourse client, built with Flutter.

Beta. Ubuntu 22.04 or later, or Debian 12 or later, on x86-64. Other Debian-based distributions that meet those requirements may work but are not tested.

Install

Add the repository, so that updates arrive with your system's regular package updates:

sudo curl -fsSLo /usr/share/keyrings/discourse-native.asc \
  https://jjaffeux.github.io/discourse-native/key.asc

Check the key before you trust it:

gpg --show-keys /usr/share/keyrings/discourse-native.asc

Register the repository:

echo "deb [signed-by=/usr/share/keyrings/discourse-native.asc] \
https://jjaffeux.github.io/discourse-native/apt/stable stable main" \
  | sudo tee /etc/apt/sources.list.d/discourse-native.list

Then install:

sudo apt update && sudo apt install discourse-native

Launch Discourse from your application menu, or run discourse-native.

There is nothing else to install. The package declares what it needs — WebKitGTK, libsecret and the rest — and apt pulls those in for you.

Canary

Canary builds land ahead of stable and break more often. Same key, different suite:

echo "deb [signed-by=/usr/share/keyrings/discourse-native.asc] \
https://jjaffeux.github.io/discourse-native/apt/canary canary main" \
  | sudo tee /etc/apt/sources.list.d/discourse-native.list

Canary versions sort below the stable release they precede, so switching back to the stable suite moves you forward onto stable rather than leaving you stranded above it.

Update

The app does not update itself. Updates come with everything else:

sudo apt update && sudo apt upgrade

Your desktop's graphical software updater will pick them up too.

Uninstall

sudo apt remove discourse-native
sudo rm /etc/apt/sources.list.d/discourse-native.list

Without the repository

Every release also carries a .deb you can install directly. apt will not deliver new versions this way — you would repeat this for each one.

sudo apt install ./discourse-native_*_amd64.deb

Signing in does not stick

Account keys are kept in your keyring, so the app needs a running Secret Service — gnome-keyring on GNOME, or KWallet with its Secret Service bridge on KDE. Without one you will appear to sign in and be forgotten on the next launch. gnome-keyring is a recommended dependency, so apt installs it unless you have told it not to install recommends.
