Discourse Native

An experimental native Discourse client, built with Flutter.

Linux builds are published on GitHub Releases. Once installed, the app updates itself — there is a Stable/Canary switch in the app's own update panel.

No builds published yet. This page is the update feed's home; it will list downloads once the release pipeline runs.

Runtime requirements (Linux)

The build is a relocatable archive, so nothing resolves these for you. On a Debian or Ubuntu system:

sudo apt install libgtk-3-0 libglib2.0-0 libwebkit2gtk-4.1-0 \
                 libsoup-3.0-0 libsecret-1-0 xdg-utils

You also need a running Secret Service provider — gnome-keyring, or KWallet with its Secret Service bridge. Account keys are stored there, and without one the app cannot keep you signed in.

WebKitGTK is linked, not loaded on demand: without libwebkit2gtk-4.1-0 the app will not start at all.

Installing

Extract the archive anywhere, then register the launcher and icons:

./install-desktop-entry.sh
