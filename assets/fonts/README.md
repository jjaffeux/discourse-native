# Bundled fonts

Lato and Open Sans are distributed under the SIL Open Font License. Their license
files are included beside the fonts and in the application assets.

Sources (downloaded September 19, 2026):
- https://github.com/google/fonts/tree/main/ofl/lato
- https://github.com/google/fonts/tree/main/ofl/opensans

Open Sans includes its variable upright and italic faces. Lato includes regular,
bold, italic, and bold italic faces. JetBrains Mono was already bundled for code.
All choices work offline; System default retains Flutter's platform typography.
