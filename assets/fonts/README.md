# Bundled fonts

Lato, Open Sans, Lora, OpenDyslexic, and JetBrains Mono are distributed under
the SIL Open Font License. Each license is included beside its fonts and in the
application assets. All choices work offline. System default uses Flutter's
platform typography.

Lato and Open Sans were downloaded September 19, 2026 from Google Fonts:

- https://github.com/google/fonts/tree/main/ofl/lato
- https://github.com/google/fonts/tree/main/ofl/opensans

Lora and OpenDyslexic were downloaded October 16, 2026 from their official
upstream repositories at these pinned revisions:

- https://github.com/cyrealtype/Lora-Cyrillic/tree/2d53b449b60e185b39f671b44fded83e0910ad30/fonts/ttf
- https://github.com/antijingoist/opendyslexic/tree/449a41bbc25f7363c540ad112dfcef2f7b340c0a/compiled

OpenDyslexic uses the v0.91.12 release.

Lora includes regular, semibold, and bold upright and italic faces.
OpenDyslexic and Lato include regular, bold, italic, and bold italic faces.
Open Sans includes variable upright and italic faces. JetBrains Mono includes
regular and bold faces for code and font assignments.
